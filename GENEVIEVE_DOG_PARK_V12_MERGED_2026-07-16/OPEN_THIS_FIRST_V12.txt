WHAT V12 IS
V12 is the single merged Dog Park app. It keeps every working V11 function
(Today, Journey, Parks, Dogs, More, risk engine, evidence records, travel,
emergency, legal, membership) and adds the interaction alert system from the
V13 colour prototype as one new screen:

  Dogs -> Dog Status & Interaction Alerts  (also under More)

NEW IN V12
- Owner-chosen dog statuses: on heat (owner can switch off any time),
  desexing status (private, undisclosed by default), and trigger
  sensitivities (skateboards/bikes, prams/mobility aids, gate crowding).
- Alert preferences: alert style, sensitivity (early/medium/close) and
  behaviour when another dog's status is undisclosed.
- Live matching: on heat + entire dog both checked in = 100% Red alert that
  stays red until a status changes or a dog checks out. Alerts appear on
  Today, on the new screen and in the Live Park state.
- Every status change, preference change and red alert is written to the
  patent evidence log.

DEPLOY (same method as V11)
1. Extract this ZIP.
2. GitHub -> your dog park repository -> Add file -> Upload files.
3. Drag the entire extracted folder contents in and commit.
4. Vercel redeploys automatically (framework preset: Other, no build step).

POST-DEPLOY CONFIRMATION CHECK
Scroll to the footer. It must read:
  "Dog Park build 2026.07.16.12 — Interaction Alerts merged"
More -> Launch Check must show:
  "Installed build: 2026.07.16.12 — Dog Status & Interaction Alerts"
If an old screen appears, the new cache name
